# GaHeal - Liquid Gallium Self-Healing PCB Trace

Problem: PCB trace crack ayithe device padipotundi.
Solution: Liquid Gallium crack ni 5 sec lo heal chestadi.

## Results
- Cracked Resistance: 1,000,000 Ohm - LED OFF - Buzzer ON
- Healed Resistance: 1.2 Ohm - LED ON - Buzzer OFF
- Healing Time: 5 Seconds

## Files
- gaheal_test.v - Verilog simulation
- gaheal_graph.py - Resistance graph
